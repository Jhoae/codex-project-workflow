# Codex 프로젝트 워크플로

**UI에서 출발해, 테스트로 신뢰를 쌓습니다.**

사용자 흐름에서 요구사항을 정하고, Codex가 작은 단위로 구현·검증하도록 돕는 지침과 템플릿 모음입니다. 작업의 근거를 파일에 남겨 다음 세션으로 이어갑니다.

## 시작하기

대상 프로젝트를 연 Codex 채팅에서 요청하세요.

```text
https://github.com/Jhoae/codex-project-workflow 를 현재 프로젝트에 적용해줘.
```

Codex가 [적용 절차](BOOTSTRAP.md)에 따라 프로젝트를 살펴보고, 기존 지침과 문서에 워크플로를 반영합니다. 기본 범위는 조사와 문서 적용이며, 이후 작업 요청과 갱신 방법은 [사용 가이드](guides/usage.md)에 있습니다.

## 더 알아보기
