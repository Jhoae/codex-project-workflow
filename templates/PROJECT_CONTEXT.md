## Update Rules

- 목표·제약·검증 공백·배포 상태·다음 시작점이 바뀌거나 Handoff할 때 갱신한다.
- 과거 실행 로그는 활성 Todo나 archive에서 찾게 하고 현재 상태만 유지한다.
- 적용 시 원본 저장소의 가이드 경로를 그대로 가정하지 않는다. 대상 프로젝트에서 실제 사용하는 문서·검사·증거 위치로 매핑한다.
